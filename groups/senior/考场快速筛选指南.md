# 提高组考场快速筛选指南（CSP-S / NOIP 提高）

> 10 分钟决策卡。数据基础：2007–2026 年提高组 122 题（CSP-S 34 + NOIP 提高 88）。
> 核心结论：DP + 贪心 + 二分是主线；难度 5 以上默认「两个算法」，难度 7–8 几乎全是多算法，数据结构常作为第二原子。

## 0 一句话流程

题号估难度 → 算复杂度预算 → 输出/载体/对象取候选族 → 强制问「第二个算法阶段」→ 必要条件排除 → 写暴力对拍。

## 1 题号先验（2022–2026）

| 位置 | 平均难度 | 主算法高频 | 多算法率 | 你要先想 |
|---|---|---|---|---|
| T1 | 3.11 | 贪心 4/9 | 33% | 贪心/模拟/简单数学，求快求稳 |
| T2 | 4.89 | 贪心 3/9、组合数学 2 | 44% | 贪心/组合数学/线性 DP |
| T3 | 6.56 | 树形 DP 3、线性 DP 3 | 78% | 树形 DP/DP+优化/字符串 |
| T4 | 7.11 | 数据结构 2、二分 2、LCA | 100% | 「DP/贪心 + 数据结构」优先 |

## 2 复杂度预算（2026 官方：Ultra 9 285K 锁频，-O2 -std=c++14 -static）

| n | 可过复杂度 | 典型 |
|---|---|---|
| ≤20 | 状压/指数 | 状压 DP、枚举子集 |
| ≤100 | O(n³) | Floyd、区间 DP |
| ≤1e3 | O(n²) | 区间/二维 DP、邻接矩阵 |
| ≤1e4 | O(n²) 小心常数 | 预处理 + DP |
| ≤1e5 | O(n log n) | 树/图/二分/BIT |
| ≤1e6 | O(n)/小常数 O(n log n) | 贪心、模拟、扫描 |
| 随机访存 | 按 2×10⁷/s 估 | 树剖/平衡树/哈希/虚树常数大 |

注意：提高组的「复杂度对、常数炸」比普及组常见；T4 有时给 2–3 秒，但不要依赖。

| 载体 | 先想 |

## 4 多算法判断（提高组最重要的一步）

近 5 年提高组多算法率：难度 3–4 为 50%，5–6 为 70%，7–8 为 85.7%。组合类型：

| 类型 | 典型 | 判断问题 |
|---|---|---|
| pipeline | 缩点→DAG DP、预处理→枚举、离线→扫描 | 能不能拆成两个先后阶段？ |
| optimize | DP/贪心 + 线段树/树状数组/堆/单调队列 | 转移/选择能否用结构加速？ |
| check | 二分答案 + 差分/贪心 check | 可行性单调吗？check 怎么做到 O(n)？ |
| hybrid | 数学推导 + 构造 + 模拟 | 是否有结论/分类讨论先降维？ |

**没有万能组合**。近 5 年只有 4 种多原子组合重复出现，全部以数据结构为枢纽：ds_maintain + LCA / 单调结构 / 线性 DP / 树形 DP。所以「DP 或贪心 + 数据结构」是提高组最该练的组合拳。

## 5 必要条件检验表

| 候选 | 必要条件 | 反例/陷阱 |
|---|---|---|
| 模拟 | 规则可逐步执行，规模容许 | 含最优选择 → 贪心/DP |
| 枚举 | 空间 ≤1e7–1e8 或可剪枝 | n=1e5 还枚举 |
| 贪心 | 交换论证/邻项比较/区间端点；局部最优不堵后继 | 0-1 背包装性价比 |
| 反悔贪心 | 先选后能撤回（堆），有交换结构 | 无交换结构硬贪 |
| 线性 DP | 按位置推进、无后效、状态可写 | 需要未来信息 |
| 树形 DP | 子树独立可合并；跨子树需换根/直径 | 忘了「子树外」信息 |
| 计数 DP | 精确计数且状态可合并 | 该用容斥/组合公式 |
| 背包 | 选/不选 + 容量；可重复性明确 | 有相邻/顺序约束 |
| 区间 DP | 目标由两端/连续子区间合成 | 子问题不连续 |
| 二分答案 | 可行性单调，check 可 O(n)~O(n log n) | 「恰好 x」不单调 |
| 双指针 | 窗口/两端移动单调不丢解 | 含负数窗口和不单调 |
| 前缀/差分 | 静态区间和/区间批量加 | 有修改 → BIT/线段树 |
| 单调栈/队列 | 左右第一个更大/更小；滑动最值 | 任意区间最值 → ST/线段树 |
| 并查集 | 只关心连通/等价，不关心路径 | 要路径长度 → 最短路 |
| 最短路 | 单/多源最小代价，边权合适 | 要经过所有点 → MST/状压 |
| MST | 连接所有点总代价最小 | 只要两点连通 → 并查集 |
| 拓扑 | 依赖/先后且无环 | 有环 → SCC/判环 |
| LCA/倍增 | 树上路径/祖先/跳步 | 非树结构 |
| 数据结构维护 | 有修改+查询且不能离线，或需在线 | 可离线/可暴力还硬上 |
| 字符串 | 匹配/前后缀/字典序 | 只需字符计数 → 桶 |
| 组合数学 | 有封闭公式/容斥结构 | 约束复杂硬套 |
| 搜索 | 状态数可接受（BFS/DFS/剪枝） | 状态爆炸 |
| 构造 | 只需可行解，可分类讨论 | 要最优 → 最值算法 |

## 6 最容易混的几对

- **贪心 vs DP**：能不能用交换论证证明「局部最优不亏」；不能就 DP。
- **DP vs 二分答案**：答案是否单调、check 是否比 DP 好写；两者常组合（二分+贪心 check）。
- **树形 DP vs 换根/树剖**：信息只在子树 → 树形 DP；需要跨子树/路径 → 换根、LCA、树剖。
- **并查集 vs 最短路**：只要连通性 → 并查集；要代价/路径长度 → 最短路。
- **线段树 vs 树状数组 vs 堆**：区间合并/复杂标记 → 线段树；单点改+前缀 → BIT；只要最值/反悔 → 堆。
- **构造 vs 结论题**：要求输出方案 → 构造；只求数值且规律强 → 数学结论。

## 7 三个例子（提高组）

**P1083 借教室（2012 提高组 D2T2，难度 3）**
- 信号：n,m≤1e6、区间操作、找「第一个不满足的申请」。
- 候选：模拟（O(nm) 超时）、差分（单次 O(n+m)）、二分答案。
- 检查：「前 k 个申请可行」关于 k 单调 → 二分；check 用差分 → O((n+m) log m)。
- 正解：二分答案 + 差分 check。陷阱：直接按申请逐个模拟。

**P2680 运输计划（2015 提高组 D2T3，难度 5）**
- 信号：树、m 条路径、最小化「最长路径时间」。
- 候选：树形 DP、二分答案、LCA/树上差分、贪心。
- 检查：答案「最长路径时间 ≤ x」关于 x 单调 → 二分；check 需要树上路径加/查 → 树上差分 + LCA，再贪心选一条边删掉。
- 正解：二分答案 + 树上差分 check（LCA 预处理）。陷阱：只想到树形 DP，或 check 写成 O(nm)。

**P9755 种树（2023 CSP-S T4，难度 6）**
- 信号：n≤1e5、树、最小化时间/最值。
- 候选：二分答案、树形 DP、贪心/堆。
- 检查：可行性对时间单调 → 二分；check 里「每个点最晚种植时间」可算，树上安排顺序用贪心（按截止时间/堆）→ 二分 + 贪心 check。
- 正解：二分答案 + 贪心（堆）check。陷阱：把「种树顺序」当成纯树形 DP。

## 8 考场动作清单

1. 先写暴力/部分分：提高组约 93.4% 的题面有分档，先保底。
2. 10 分钟内出候选；难度 ≥5 时强制写「两个阶段」；写不出就回到暴力。
3. 复杂度先算再写：提高组 TLE 大多是「复杂度选错」，不是常数。
4. 正解写完必须和暴力随机对拍，尤其是贪心/二分/树形 DP。
5. 交卷前检查：多组数据清空、long long、递归深度/栈、内存（256–512MB）、文件名。

## 9 时间分配建议（以 4.5 小时 NOIP / 4 小时 CSP-S 为例）

- T1：30–40 分钟，稳过。
- T2：45–60 分钟，拿满或高分。
- T3：60–75 分钟，先暴力再正解。
- T4：60–80 分钟，先拿部分分，再冲正解；两个候选都像时选实现短、分档覆盖大的。
- 留 20 分钟检查与对拍。
