# 普及组考场快速筛选指南（CSP-J / NOIP 普及）

> 10 分钟决策卡。数据基础：2007–2026 年普及组 80 题（CSP-J 32 + NOIP 普及 48）。
> 核心结论：普及组近一半是「模拟/枚举/排序」，DP 从难度 3 才开始当主角，高级算法是点缀。

## 0 一句话流程

看题号 → 估难度 → 算复杂度预算 → 按「输出/载体」取 2–3 个候选 → 用必要条件排除 → 写暴力对拍。

## 1 题号先验（2022–2026）

| 位置 | 平均难度 | 主算法高频 | 你要先想 |
|---|---|---|---|
| T1 | 1.40 | 模拟×4/5 | 直接模拟，注意读入/边界/字符串 |
| T2 | 2.00 | 模拟、数学、贪心 | 枚举/排序/简单数学 |
| T3 | 3.20 | 贪心×3/5、模拟、数学 | 先试「排序后贪心」，不行再 DP/前缀 |
| T4 | 3.80 | 线性 DP×3/5、最短路、背包 | DP（线性/背包）优先，其次 BFS/最短路/树遍历 |

多算法率：T1/T2 约 0%，T3/T4 约 20%；只有 T4 且难度 ≥4 才考虑「DP/贪心 + 前缀和/单调队列」。

## 2 复杂度预算（2026 官方：Ultra 9 285K，-O2 -std=c++14 -static）

| n | 可过复杂度 | 说明 |
|---|---|---|
| ≤10 | 阶乘/暴搜 | 全排列 |
| ≤20 | 状压/指数 | 2^n |
| ≤100 | O(n³) | 三重枚举、Floyd |
| ≤1e3 | O(n²) | 区间 DP、二维 DP |
| ≤1e4 | O(n²) 小心常数 | 能过但别写重 |
| ≤1e5 | O(n log n)/O(n) | 排序、二分、前缀、图/树 |
| ≤1e6 | O(n)/小常数 O(n log n) | 模拟、贪心、前缀 |

经验：1 秒保守按 2×10⁸ 次基本操作估；普及组题很少卡常，拿不准时先写暴力。

## 3 题面信号 → 候选算法

**输出**：

- 求值/模拟类 → 模拟、枚举、排序
- 最小/最大 → 枚举、贪心、线性 DP、最短路
- 计数 → 模拟、枚举、计数 DP
- 构造/输出方案 → 模拟、排序、贪心
- 判定 → 模拟、最短路/BFS

**载体**：

| 载体 | 先想 |
|---|---|
| 序列/数组 | 模拟、线性 DP、排序、前缀和 |
| 字符串 | 模拟、字符串处理（哈希/Trie 只在必要时） |
| 多重集/物品 | 排序、贪心、枚举、背包 |
| 网格/棋盘 | 模拟、BFS/最短路、DP |
| 图 | 最短路、BFS、树遍历 |
| 整数/数论 | 数学推导、枚举、数论 |

**难度**：

| 难度 | 先想 |
|---|---|
| 1–2 | 模拟/枚举/排序/简单数学（DP 极少） |
| 3–4 | 线性 DP、贪心、数学、最短路、树遍历 |
| 5 | 线性 DP + 优化（单调队列/前缀）、区间 DP |

## 4 必要条件检验（不满足就排除）

| 候选 | 必要条件 | 常见反例 |
|---|---|---|
| 模拟 | 规则能一步步执行 | 含「最优选择」→贪心/DP |
| 枚举 | 搜索空间 ≤1e7–1e8 或可剪枝 | n=1e5 还枚举 |
| 排序 | 答案只依赖大小/顺序 | 需要原下标没存 |
| 贪心 | 能交换论证/邻项比较/区间端点 | 0-1 背包按性价比贪心 |
| 前缀和/差分 | 静态区间和/区间批量加 | 有修改还硬套 |
| 二分答案 | 可行性对答案单调，check 可 O(n) | 「恰好 x」不单调 |
| 线性 DP | 决策按位置推进、无后效、状态能写出来 | 需要未来信息 |
| 背包 DP | 选/不选 + 容量约束、可重复性明确 | 有顺序/相邻约束 |
| 最短路/BFS | 求最少步数/最小代价，边权合适 | 要经过所有点 |
| 树遍历 | 树结构、子树独立 | 需要跨子树信息 |

## 5 最容易混的几对

- **模拟 vs 枚举**：模拟是「按规则走」，枚举是「试所有可能」；很多题两者都用，取决定复杂度的那个当主算法。
- **排序 vs 贪心**：排序只是手段；如果排序后还要按规则选，主算法记贪心。
- **贪心 vs DP**：能不能用交换论证证明「局部最优不亏」；不能就 DP。
- **DP vs 搜索**：状态空间小、无后效 → DP；状态少但转移复杂/需要剪枝 → 搜索。
- **最短路 vs 树遍历**：一般图/网格 → 最短路/BFS；树 → 遍历/树形 DP。

## 6 三个例子（普及组）

**P9749 公路（2023 CSP-J T2，难度 2）**
- 信号：序列、最小花费、n≤1e5。
- 候选：贪心、DP、最短路。检查：没有单调可行性（排二分），没有子区间合并（排区间 DP）；「在更便宜的站之前尽量少买」可以交换论证 → 贪心。
- 正解：单调栈/预处理每个位置后面第一个更便宜的站，按段贪心买油，O(n)。陷阱：直接模拟每次加油会超时。

**P5662 纪念品（2019 CSP-J T3，难度 4）**
- 信号：T 天、N 种物品、M 元、最大收益。
- 候选：模拟、贪心、DP。检查：单件收益排序贪心有反例（同一天可反复买卖、受现金限制）；每天决策只依赖当天现金与次日价格、无后效 → 完全背包。
- 正解：逐日做完全背包（容量=现金，价值=次日价−今日价），O(TNM)。陷阱：把它当「跨天持有」的复杂状态。

**P11230 接龙（2024 CSP-J T4，难度 5）**
- 信号：序列/多重集、判定 q 个任务、n 与总长 1e5。
- 候选：搜索/最短路、DP、DP+单调队列。检查：状态按轮数推、无后效 → DP；转移要在词库里找「以某值开头/结尾的连续段」，用双指针/单调队列优化。
- 正解：按轮 DP + 每人的词库预处理左右端点，O(r·Σl)。陷阱：把「不能同一个人连续」漏掉；暴力枚举转移超时。

## 7 考场动作清单

1. 先写暴力/部分分（普及组约 77.5% 的题面有分档），保证小数据分。
2. 10 分钟内按 §0 走完候选；超过 10 分钟没思路就先交暴力。
3. 写正解前手推样例；写完和暴力随机对拍。
4. 交卷前检查：多组数据清空、数组边界、long long、文件名/输入输出。

## 8 时间分配建议（以 CSP-J 3.5 小时为例）

- T1 + T2：40–50 分钟内稳过，不纠结完美写法。
- T3：50–60 分钟（贪心/DP 先写暴力再优化）。
- T4：60–70 分钟（先拿部分分，再冲正解）。
- 留 15–20 分钟检查与对拍。
