# 分难度算法筛报告与考场指南（归档）

> 归档日期：2026-11-24。把 2007–2026 年真题按 **普及组 / 提高组** 拆成两个数据集，分别产出「算法筛选报告」与「考场快速筛选指南」。
> 这是研究归档，配套的公开版趋势报告在仓库根目录 README.md。

## 一、数据集

| 组 | 范围 | 题数 | 文件 |
|---|---|---|---|
| 普及 | CSP-J（2019–2026）+ NOIP 普及组（2007–2018） | 80 | junior.csv |
| 提高 | CSP-S（2019–2026）+ NOIP 提高组（2007–2018）+ NOIP（2020–2025） | 122 | senior.csv |

字段：pid / year / competition / group / difficulty / title / source / primary / primary_family / atoms / atom_count / multi / combo_type / position / complexity / ops_est / n_order / object / carrier / property / era / diff_band。

统计口径：
- 2022–2026 的题使用「紧口径原子」（主算法 + 不可省略的第二阶段；排序/前缀和/二分查找等工具不计原子）；
- 2007–2021 的题使用第一轮「主算法 + 次要算法」作为组合代理（combo_type=proxy），不与紧口径直接比较；
- position 只有 2022–2026 有（每年组别 4 题，T1–T4）。

## 二、文档

- junior/算法筛选报告.md —— 普及组 80 题：算法分布、难度分层、题号先验、载体/对象、复杂度、候选锚定评估、备考优先级。
- junior/考场快速筛选指南.md —— 普及组 10 分钟决策卡。
- senior/算法筛选报告.md —— 提高组 122 题：同结构，另含 CSP-S/NOIP 对比与多算法/离子分析。
- senior/考场快速筛选指南.md —— 提高组 10 分钟决策卡。

## 三、统计与图表

- out/junior-tables.md、out/senior-tables.md：全量交叉表（构成、主算法、难度分层、年代、组别、多算法、题号先验、载体/对象、复杂度、留一法）。
- out/junior-*.png、out/senior-*.png：报告用图（主算法分布、算法族×难度、题号×主算法、候选锚定）。
- out/summary.json：机器可读汇总。

## 四、脚本与标注

- scripts/build_dataset.py：从原始研究目录生成 junior.csv / senior.csv（依赖完整研究工作区，归档中仅作留档参考）。
- scripts/analyze_groups.py、scripts/figures_groups.py：统计与画图。
- scripts/fetch_high.py：抓取 2007–2021 年 15 道提高组高难题题面（原题面不随仓库分发）。
- annotations/：上述 15 道高难题的补标结果（ann_high_a/b.jsonl）与事实表（facts_high.json），用于补齐提高组数据集。

## 五、归档说明

- 题干/题面版权归 CCF 与洛谷，仓库**不收录**题目原文，只保留自制的统计、标注与文档。
- 提高组 2007–2021 的 15 道高难题标注是本次补标，confidence 多为 medium/low，相关结论只作方向参考。
- 难度为洛谷 2026-07-02 改版后的 1–8 档主观评定，会调整；2026 年只有 CSP-J/S。
- 主算法是「主流正解」的归纳，一题多解只取一种。
- 脚本依赖原始研究工作区（catalog/题面/标注），不在本仓库内；直接使用 CSV 即可复现报告中的统计。

## 六、关键结论（速览）

- 普及组：基础实现 47.5%、DP 16.2%、数学 12.5%、贪心 8.8%、图论/树 7.5%；近 5 年多算法仅 10%；题号 T1 平均 1.40 → T4 3.80。
- 提高组：DP 23.0%、基础实现 14.8%、贪心 13.1%、数学 11.5%、图论/树 9.8%、二分 9.8%、数据结构 7.4%；近 5 年多算法 63.9%（难度 7–8 达 85.7%），重复组合全部以数据结构为枢纽；题号 T1 3.11 → T4 7.11。
